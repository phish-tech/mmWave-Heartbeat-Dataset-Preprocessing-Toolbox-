> 我的研究方向主要集中在**非接触式生理测量**和**多模态信号-人工智能系统**，专注于在真实复杂场景与约束下实现鲁棒的感知与学习。我目前的兴趣包括**毫米波雷达传感**、**心电图 (ECG) 驱动建模**以及**信号对齐的多模态学习**。

---

## 🔬 研究方向

- **非接触式生理测量 (Non-contact Physiological Measurement)**
  - 基于毫米波雷达的生命体征感知及其鲁棒性研究
  - 基于相机/rPPG 的生理特征推断
- **多模态信号融合 (Multimodal Signal Fusion)**
  - ECG × 毫米波 (及其他模态) 的生理状态建模融合
  - 时序信号的对齐、去噪及不确定性感知学习
- **面向学习系统的信号处理 (Signal Processing for Learning Systems)**
  - 生理信号的特征与表征工程
  - 面向落地部署的算法流水线开发 (高效、可复现、可审计)

## 💻 精选项目与开源贡献

- **[PhysioAugment](https://github.com/phish-tech/PhysioAugment)** *(开源项目)*
  一个专为 1D 生理信号数据增强设计的 Python 库，助力生物医学时序数据的鲁棒模型训练。
- **毫米波心率与呼吸率估计预处理工具箱**
  正在构建一个基于集合经验模态分解 (EEMD) 的算法工具箱，用于通过毫米波雷达精准估计心率和呼吸率。
- **ECG × 毫米波融合感知系统 (进行中)**
  构建跨模态生理感知流水线，旨在解决运动和噪声干扰下的可靠生理状态估计问题。
- **超表面传感前沿探索**
  早期探索与超表面相关的感知与交互场景及其测量装置搭建。
